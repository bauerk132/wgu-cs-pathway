# WGU CS Pathway

Private Sites tracker for the November 4, 2026 personalized WGU Computer Science degree plan. The official roster is versioned separately from the tracker’s editable study order and progress.

Run npm run build and npm run validate before publishing. The Worker uses Sites identity and a D1 binding named DB. The initial migration lives in drizzle. npm run dev serves local preview with temporary SQLite data and a preview-only identity.

The deployed app provides links and task handoffs for Life HQ, Todoist, Google Tasks, and Google Calendar. Private Sites connector eligibility was unavailable in this workspace when built.
